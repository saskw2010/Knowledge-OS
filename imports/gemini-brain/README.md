# Gemini Import Workspace

هذه مساحة العمل المخصصة لمهمة **جيمناى امبورت**. ابدأ من [`../../docs/MANUS-GEMINI-IMPORT-WORKSPACE-INDEX.md`](../../docs/MANUS-GEMINI-IMPORT-WORKSPACE-INDEX.md).

- `raw/`: الملفات الأصلية.
- `catalog/`: فهرس الملفات والبيانات الوصفية.
- `knowledge/`: المعلومات المستخرجة.
- `plans/`: الخطط التنفيذية.
- `decisions/`: القرارات والافتراضات.
- `links/`: روابط Manus وGitHub.
- `deliverables/`: المخرجات النهائية.
