# Knowledge-OS Glossary

**Status:** Proposed foundation addition.

- **Canonical Concept:** Integration anchor representing a concept across multiple systems; not an assertion of one universally correct meaning.
- **Classification System:** A named, versioned scheme that organizes knowledge for a particular purpose.
- **Classification Node:** A node whose identity and position belong to one classification system.
- **Concept Graph:** Graph of concepts and semantic relations within or across domains.
- **Crosswalk:** Explicit mapping between nodes in different classification systems or between a classification node and a canonical concept.
- **Dataset Item:** A derived training or evaluation record generated from eligible graph claims.
- **Epistemic Status:** Controlled label describing how an assertion is known, such as official, extracted, inferred, disputed, or rejected.
- **Knowledge Factory:** Pipeline that collects, preserves, normalizes, resolves, expands, validates, and publishes knowledge.
- **Knowledge Graph:** Structured graph of entities, claims, and typed relations.
- **Meta-Knowledge:** Knowledge about classification, provenance, validation, disagreement, usage, and relationships among knowledge systems.
- **Meta-Knowledge Graph:** Graph that connects concepts, claims, sources, perspectives, and classification systems while preserving provenance and disagreement.
- **Model-Reconstructed View:** A classification generated by a language model as an explicit reconstruction, not a direct reading of internal model weights.
- **Ontology:** Formal specification of entity types, relation types, constraints, and meanings.
- **Perspective:** Purpose or rule through which knowledge is organized.
- **Provenance:** Trace of where an entity, label, claim, mapping, or relation originated and how it was processed.
- **Source Snapshot:** Immutable imported representation of a source system at a particular version.
- **Taxonomy:** Controlled hierarchical organization, usually using broader and narrower relations.
- **Teacher Model:** Model used to generate, critique, or revise dataset candidates under validation controls.
- **Validation Evidence:** Sources, tests, comparisons, or expert decisions supporting a validation result.
