كيف يعمل النظام؟

1 · Dataset

بيانات متخصصة لـChat أو Agent أو Coding أو ERP، مع metadata تصف النية والمجال والأداة المطلوبة.

2 · Adapter

تدريب LoRA فوق Base Model ثابت، ثم حفظ الأوزان ونسخة البيانات ونتائج القياس.

3 · Registry

سجل يجمع الوصف الدلالي، القدرات، اللغات، الإصدارات، الأمثلة، القيود، وحالة الاختبارات.

4 · Router

يستخدم Metadata والتشابه الدلالي والقواعد لاختيار Adapter أو أكثر، أو Tool/Plugin مناسب.

  "status": "validated"

إضافة Adapter لا تعني إعادة تدريب Router تلقائيًا. نبدأ بالتسجيل والاختبار؛ نعيد تدريب Router فقط إذا ظهرت أخطاء اختيار متكررة أو أُضيف مجال جديد جذريًا.
