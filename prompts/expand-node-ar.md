# Expand Knowledge Node Prompt — Arabic

وسّع العقدة المعرفية المحددة أدناه داخل Knowledge-OS من غير إعادة بناء المعرفة البشرية كلها.

## المدخلات

- `concept_id`
- الاسم العربي والإنجليزي
- التعريف الحالي
- الآباء والمناظير الحالية
- العلاقات المعروفة
- الحد الأقصى للعمق وعدد العقد

## المطلوب

1. حدّد الفروع الطبيعية المباشرة للعقدة.
2. استخرج المفاهيم الأساسية والمناهج والمهارات والأدوات والتطبيقات بوصفها أنواع عقد منفصلة.
3. أنشئ علاقات غير هرمية عند الحاجة.
4. لا تنشئ عقدة موجودة بالفعل باسم بديل؛ اقترح alias أو canonical match.
5. لا تتجاوز حدود المجال أو عمق التوسيع.
6. اكتشف الدوران والتكرار والتسرب إلى مجالات بعيدة.
7. ميّز بين المعرفة المستقرة والشائعة والمختلف عليها والمستنتجة.
8. اقترح مصادر تحقق ولا تخترع مراجع.

## المخرجات

أخرج JSON يحتوي على:

- expanded_concept_id
- proposed_concepts
- proposed_relations
- aliases
- possible_duplicates
- disputed_boundaries
- evidence_needed
- stop_reasons
- quality_warnings

كل Concept وكل Relation يجب أن يتوافق مع JSON Schemas الموجودة في مجلد `schemas/`، وأن يحتوي على provenance يحدد تشغيل النموذج الذي أنشأه.
